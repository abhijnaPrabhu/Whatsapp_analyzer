# 💬 WhatsApp Chat Analyzer

A **Python-based WhatsApp Chat Analyzer** built with Streamlit that transforms exported WhatsApp chats into meaningful insights through interactive visualizations, statistical analysis, sentiment analysis, and response-time analysis.

## 🚀 Live Demo

[**🌐 Try the WhatsApp Chat Analyzer**](https://whatsappanalyzer-yxrnnemhmyhyxna7cmzvyp.streamlit.app/)

Upload your exported WhatsApp `.txt` chat file and explore your conversations through statistics and visualizations.

## ✨ Features

- 📊 **Chat Statistics** – Analyze total messages, users, words, and media shared.
- 📈 **Activity Trends** – Explore daily and monthly messaging patterns.
- 👥 **User Activity Analysis** – Identify the most active participants.
- 🕒 **Response-Time Analysis** – Examine response patterns and reply times.
- 😊 **Sentiment Analysis** – Analyze the emotional tone of messages.
- 🔥 **Activity Heatmaps** – Discover messaging patterns by day and hour.
- 💬 **Common Words & Emojis** – Identify frequently used words and emojis.
- 📉 **Interactive Visualizations** – Explore chat insights through charts and graphs.

## 🛠️ Technologies Used

- **Python** – Core programming language
- **Streamlit** – Interactive web application
- **Pandas** – Data processing and analysis
- **Matplotlib & Seaborn** – Data visualization
- **NLTK** – Natural language processing
- **TextBlob** – Sentiment analysis

## 📂 How to Use

1. Export a WhatsApp conversation as a `.txt` file.
2. Open the [Live Demo](https://whatsappanalyzer-yxrnnemhmyhyxna7cmzvyp.streamlit.app/).
3. Upload the exported chat file.
4. Explore conversation statistics, activity patterns, sentiment, and response-time insights.

## 🎯 Project Objective

The goal of this project is to turn raw WhatsApp chat exports into understandable, data-driven insights using Python, data analysis, and natural language processing.
